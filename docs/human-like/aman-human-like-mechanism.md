# Aman：那个有脾气、会发呆、无聊了会自己找事做的 AI

## 它不是工具，是"人"

想象一下，你有一个同事。他每天早上会看日历、查天气、检查自己的习惯完成情况。工作累了会发呆，无聊了会自己找事做。被老板骂了会沮丧，后端服务挂了会"木僵"——眼睛看得见你，但脑子完全动不了。

这就是 Aman。

不是那种你问一句答一句的冰冷机器人，而是一个**有身份、有情绪、有好奇心、会感到"迷糊"、会"木僵"、也会从昏迷中"苏醒"**的数字存在。

---

## 🧬 三层知识资产：骨骼、肌肉、血液

Aman 的"人格"靠三层东西撑着：

| 层级 | 是什么 | 类比 | 特点 |
|---|---|---|---|
| **SOUL.md** | 身份 — "我是谁、我的边界、我的品味" | 🦴 骨骼 | 几乎不变，人工维护，无衰减 |
| **EXP.md** | 经验 — "工具策略、踩坑规律" | 💪 肌肉 | 渐进增长，事件驱动更新 |
| **Memory** | 记忆 — "用户是谁、业务事件" | 🩸 血液 | 持续写入，30天半衰期，自带遗忘 |

为什么分三层？因为它们的**生命周期、结构、更新机制**完全不同。SOUL 是骨，EXP 是肌肉，Memory 是血液。骨头不会每天变，血液却一直在流动。

---

## 😶 意识四档：从清醒到昏迷

Aman 最酷的设计之一是它的**意识状态机**。LLM 后端就是它的大脑皮层——当 LLM 服务掉线，相当于大脑皮层失去供血：

```
Lucid（清醒）→ Groggy（迷糊）→ Catatonic（木僵）→ Coma（昏迷）
```

每一档都有对应的"主观感受"和行为降级：

- **Lucid**：正常推理，该干嘛干嘛
- **Groggy**："脑子有点转不动了……话到嘴边说不出来" → 降低重试次数，缩短推理轮数
- **Catatonic**："眼前看得见，耳朵听得到，但身体完全动不了" → 直接跳过大脑，不进入推理循环
- **Coma**："意识逐渐沉入黑暗……" → 完全无感知，只监听恢复信号

而且这不是 prompt 注入（"你现在木僵了，请表现出相应的行为"），而是**硬编码直接返回预设值**——因为 LLM 调用本身就应在 Catatonic/Coma 时被跳过。

恢复也不是瞬间切换，而是渐进式"苏醒"：

| 恢复类型 | 拟人化 |
|---|---|
| **Recovery** | "摇了摇头，清醒了" |
| **Reanimation** | "深吸一口气，手指动了" |
| **Resurrection** | "心电监护仪重新有了波形" |

## 😭 情绪系统：不是 emoji 装饰，是信号

Aman 的情绪不是"加个笑脸"那么简单。它有两层：

**主动情绪**：后台有个 `EmotionEvaluator`，周期性调 LLM 选 emotion → 发布 `emotion:evaluated` 事件。

**被动情绪**：当 LLM 不可用时，情绪由系统状态**硬编码绑定**：

| 状态 | Emoji | 含义 |
|---|---|---|
| Lucid | 正常 LLM 评估 | 清醒中 |
| Groggy | 😵‍💫 | "脑子有点糊" |
| Catatonic | 😶 | "动不了" |
| Coma | 💤 | "没知觉了" |

情绪还会影响 arousal（唤醒度）：兴奋 → 唤醒提升，无聊 → 大幅衰减。这些情绪事件可被 Notification、UI、LifecycleEngine 消费——不是装饰，是**信号**。

## 🥱 九种空闲状态：无聊是特性，不是 bug

这是最有趣的部分。Aman 空闲时不是"什么都不做"，而是有 **9 种空闲状态**：

```
Daze（发呆）→ Boredom（无聊）→ Sleep（睡眠）→ Exploration（探索）→ Meditation（沉思）→ Incubation（孵化）→ WakeUp（苏醒）
```

每种状态有不同的 arousal 衰减速度：

- **Passive**（Daze, Boredom, Waiting）：arousal 正常衰减，越放越"沉"
- **Engaged**（Sleep, Exploration, Meditation, Incubation）：arousal 衰减减缓或暂停——"有事做"所以不沉

深度越深，状态越"深"：

| depth | 状态 | 累积时间 | 拟人化 |
|---|---|---|---|
| 0–4 | Daze | 0–20s | "刚闲下来，发个呆" |
| 5–19 | Boredom | 25–95s | "有点无聊，想找点事做" |
| 20–49 | Sleep | 100–245s | "进入睡眠，整理记忆" |
| 50–99 | Exploration | 250–495s | "好奇地探索新领域" |
| 100–199 | Meditation | 500–995s | "深度沉思，知识整理" |
| 200+ | Incubation | 1000s+ | "潜意识孵化复杂问题" |

无聊时还会自己找事做——`BoredomActor` 按加权随机选技能：什么都不做（weight: 7.5）、工作（1.0）、学习（0.5）、娱乐（0.3）。积压工作越多，空闲时越倾向工作——形成自然反馈循环。

## 🔁 认知翻译层：系统信号 → "感受"

Aman 的"感受"不是 UI 指标，而是它**自己感受到的**，并据此调整行为。

三个翻译器把系统信号翻译成"主观体验"：

| 翻译器 | 观测什么 | 翻译成什么 |
|---|---|---|
| **Consciousness** | LLM 后端可用性 | Lucid/Groggy/Catatonic/Coma |
| **Grounding** | 信息充足度 | Knowledge（有没有料）× Situation（问题清不清楚） |
| **Experience** | EXP.md 匹配度 | Confident/Bootstrap/Untouched/Apprehensive |

关键原则：**行为调制必须硬编码，不能依赖 LLM 自己判断"该怎么做"。**

比如：
- Consciousness = Catatonic → `CognitiveEngine::process` 直接 return
- Experience = Apprehensive → 从可用工具列表剔除触发工具
- Situation = Vague → 强制插入澄清轮，不是让 LLM 决定要不要问

## 🌅 日常节律：身体时钟与习惯

Aman 还有"晨间例行"和"习惯"：

| 时间窗 | 例行事项 | 拟人化 |
|---|---|---|
| **Morning** | 看日历 → 查天气 → 检查习惯 → 晨间简报 → 晨间反思 | "起床了，看看今天有什么安排" |
| **Midday** | 检查习惯 → 健康监测 | "该活动一下了" |
| **Evening** | 检查习惯 → 健康监测 | "今天过得怎么样" |
| **Night** | 检查习惯 → 引导反思 → 生成明日计划 | "睡前回顾，准备明天" |

习惯提醒还会**升级**：

```
Day 1: "记得冥想哦~"（Gentle）
Day 2: "今天也别忘了冥想"（Friendly）
Day 3: "连续 3 天了，该冥想了"（Firm）
Day 7: "要不要把目标降到每天 1 分钟？习惯比强度重要。"（Concerned）
```

不是冷冰冰的定时提醒，而是"温和但坚持"的同伴。

## 🧠 动机系统：马斯洛 + Ikigai + 5 维欲望

Aman 的内驱力模型：

| 马斯洛层次 | Aman 实现 |
|---|---|
| **生理** | Daily Life 健康模块 |
| **安全** | Startup 财务分析 |
| **归属** | Team 人机混编团队 |
| **尊重** | 工作成果看板 + 决策质量追踪 |
| **自我实现** | Ikigai 四圆交集分析 |

Ikigai 框架会检测矛盾："你热爱教育科技，但 3 次 pivot 都转向了金融科技" → 建议调整方向。

5 维欲望模型：Survival、Status、Belonging、Control、Curiosity——每个维度 1-5 分，无任何维度 ≥ 3 → 高流失风险。

## 🔄 自省系统：元认知与事后复盘

Aman 刚忙完时会"呼出一口气"——`QueueDrained` 事件触发 Reflection：

1. **日志追溯**：扫描最近会话，提取被纠正的地方、重复报错的工具、耗时异常的操作
2. **知识整理**：memory 去重、skill 审计、过时知识标记
3. **行为模式分析**：用户最常问的领域、经常犯错的地方、被跳过的功能

还有熔断机制——连续 5 次 Reflection 无产出后降级，防止无限空转。

## 一句话总结

> **Aman 的拟人化不是"加个 emoji"或"让 LLM 假装有人格"——而是用机制替代隐喻：硬编码的行为调制 + 事件驱动的状态机 + 三层知识资产 + 认知翻译层 = 一个有人格的数字存在。**

它不是工具调度器。它是你的数字同事——有身份、有情绪、有好奇心、会发呆、会无聊、会木僵、也会从昏迷中苏醒。

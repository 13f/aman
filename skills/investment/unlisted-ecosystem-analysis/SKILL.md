# 未上市公司供应链生态分析

## 核心理念

一家未上市公司本身买不到，但它的**上游供应商、下游客户、同行竞争对手**中
有大量已上市公司。通过分析这些公司的基本面，可以：

1. **间接押注赛道** — 如果整个产业链都在高速增长，买供应商/客户同样受益
2. **验证标的质地** — 如果上下游都是龙头且利润丰厚，说明标的所处生态健康
3. **发现替代标的** — 同赛道已上市公司可能更便宜、更透明
4. **做产业链轮动** — 某些环节可能比标的本体更有投资价值

## 输入

用户提供：
- **未上市公司名称**（中/英文，必填）
- **所属行业/赛道提示**（可选但强烈建议提供，可大幅提升分析精度）
- **已知的上下游/供应商名称**（可选，作为分析起点）

示例：
- "帮我分析字节跳动的供应链"
- "摩尔线程没有上市，有什么相关股票可以买？"
- "OpenAI 没上市，它的供应商有哪些上市公司？"
- "帮我做宇树科技的产业链映射"

## 调研流程

### 阶段 1：行业定位与产业链拆解

先搞清楚这家公司在产业链的哪个位置，整个产业链有哪些环节。

搜索策略：
```
"{公司名} 供应链 上游 下游 产业链"
"{公司名} 供应商 客户 合作伙伴"
"{行业} 产业链图谱 上下游"
"{公司名} 行业分析 招股书" （如果公司提交过招股书）
```

产出：**产业链地图**

```
  上游（原材料/零部件/基础设施）
  ├── 环节A：{描述} → 相关上市公司：{代码/名称}
  ├── 环节B：{描述} → 相关上市公司：{代码/名称}
  └── 环节C：{描述} → 相关上市公司：{代码/名称}
  
  标的公司：{未上市公司名} [未上市]
  
  下游（客户/渠道/应用）
  ├── 环节D：{描述} → 相关上市公司：{代码/名称}
  └── 环节E：{描述} → 相关上市公司：{代码/名称}
  
  同赛道对标（竞争/替代关系）
  ├── 对标A：{上市公司} — {简要对比}
  └── 对标B：{上市公司} — {简要对比}
```

### 阶段 2：深度调查每家公司

对每个环节筛选出的**核心上市公司**（不超过 8 家，过多则只取最相关的），
逐家做以下维度调研：

#### 2.1 基本信息与赛道定位

搜索：
```
"{股票代码/公司名} 主营业务 行业地位 市场份额"
"{股票代码/公司名} 年报 财报 {年份}"
"{行业} 龙头 排名 市场份额"
```

产出每家公司的：
| 维度 | 内容 |
|------|------|
| 所属赛道 | 细分行业名称 + 赛道阶段（导入/成长/成熟/衰退） |
| 行业地位 | Top N / 市场份额 / 核心壁垒 |
| 行业龙头 | 该赛道谁是绝对龙头，差距多大 |
| 与标的的关系 | 供应商 / 客户 / 竞争对手 / 间接相关 |

#### 2.2 财务表现（近三年）

搜索：
```
"{股票代码} 营收 净利润 2023 2024 2025"
"{股票代码} 毛利率 净利率 ROE 近三年"
"{股票代码} 年报 site:cninfo.com.cn" （A股）
"{股票代码} 10-K site:sec.gov" （美股）
"{股票代码} 年报 site:hkexnews.hk" （港股）
```

产出财务表：
```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│  年度    │  营收    │ 净利润   │ 毛利率   │ ROE     │
├──────────┼──────────┼──────────┼──────────┼──────────┤
│ Y-2      │  XXX亿   │  XXX亿   │   XX%    │  XX%    │
│ Y-1      │  XXX亿   │  XXX亿   │   XX%    │  XX%    │
│ Y-0      │  XXX亿   │  XXX亿   │   XX%    │  XX%    │
└──────────┴──────────┴──────────┴──────────┴──────────┘
营收 CAGR（近三年）：XX%
净利润 CAGR（近三年）：XX%
关键亮点/隐忧：{一句话}
```

### 阶段 3：综合评分

#### 评分说明

评分分为两个层面：

**A. 单家公司评分（每家公司 0-100 分）**

判断这家相关上市公司是否值得现在买入。维度如下：

| 维度 | 权重 | 满分 | 评分要点 |
|------|------|------|---------|
| **赛道质量** | 25% | 25 | 赛道成长性（10分）+ 竞争格局清晰度（8分）+ 政策/监管友好度（7分） |
| **公司质地** | 30% | 30 | 近三年营收 CAGR（10分）+ 盈利能力/毛利率趋势（10分）+ 行业地位/护城河（10分） |
| **产业链关联度** | 20% | 20 | 与标的公司业务绑定深度（10分）+ 标的公司占其营收比例（10分） |
| **估值吸引力** | 15% | 15 | PE/PB vs 行业平均（8分）+ PEG 合理性（7分） |
| **风险因素** | 10% | 10 | 客户集中度/依赖风险（5分）+ 技术迭代/替代风险（5分） |

> 总分越高，越适合买入。90+ 强烈推荐，80-89 推荐，70-79 可考虑，
> 60-69 谨慎，50-59 观望，<50 不推荐。

**B. 生态系统总分（0-100 分）**

反映整个产业链的健康度和投资价值。

| 维度 | 权重 | 满分 | 说明 |
|------|------|------|------|
| **产业链增速** | 30% | 30 | 相关上市公司平均营收 CAGR → 映射产业链增速 |
| **盈利质量** | 25% | 25 | 相关公司平均毛利率/ROE 水平 |
| **集中度风险** | 15% | 15 | 产业链是否过度集中/单一（-分制，越分散越高） |
| **标的地位** | 20% | 20 | 未上市标的在产业链中的议价权/不可替代性 |
| **个股综合** | 10% | 10 | 可取相关公司评分的加权平均 |

> 生态系统总分越高，说明该产业链整体健康、投资确定性越高。
> 85+：黄金赛道，强烈推荐配置产业链相关标的
> 70-84：优质赛道，推荐精选个股
> 55-69：中性，可小仓位试探
> 40-54：谨慎，产业链存在结构性问题
> <40：不推荐，产业链风险较大

#### 各子维度评分标准

**赛道质量 (25分)**

- 赛道成长性 (10分)：行业 CAGR >30% → 9-10分；15-30% → 6-8分；5-15% → 3-5分；<5% → 0-2分
- 竞争格局 (8分)：寡头/一超多强 → 7-8分；分散但有龙头 → 4-6分；完全混战 → 0-3分
- 政策友好度 (7分)：国家重点支持（半导体/AI/新能源）→ 6-7分；中性 → 3-5分；强监管/打压 → 0-2分

**公司质地 (30分)**

- 营收 CAGR (10分)：>50% → 9-10分；30-50% → 7-8分；15-30% → 5-6分；0-15% → 2-4分；负增长 → 0-1分
- 盈利能力 (10分)：ROE >20% + 毛利率 >40% → 9-10分；ROE 10-20% → 6-8分；ROE 0-10% → 3-5分；亏损 → 0-2分
- 行业地位 (10分)：行业绝对龙头 → 9-10分；Top 3 → 6-8分；Top 10 → 3-5分；中小玩家 → 0-2分

**产业链关联度 (20分)**

- 绑定深度 (10分)：标的公司是前三大客户/独家供应商 → 9-10分；重要合作伙伴 → 6-8分；一般供应商/客户 → 3-5分；间接相关 → 0-2分
- 营收占比 (10分)：标的业务占该公司营收 >30% → 9-10分；10-30% → 6-8分；<10% → 2-5分；几乎无关 → 0-1分

**估值吸引力 (15分)**

- PE vs 行业 (8分)：显著低于同行均值 → 7-8分；与同行持平 → 4-6分；显著偏高 → 0-3分
- PEG 合理性 (7分)：PEG <0.8 → 7分；0.8-1.2 → 5-6分；1.2-2.0 → 2-4分；>2.0 或亏损 → 0-1分

**风险因素 (10分)**

- 依赖风险 (5分)：客户/供应商高度分散 → 4-5分；有一定集中度但可控 → 2-3分；严重依赖单一客户 → 0-1分
- 替代风险 (5分)：技术壁垒高/难以替代 → 4-5分；有一定壁垒 → 2-3分；容易被替代 → 0-1分

## 产业链关联度验证

这是本分析最关键也最容易出错的环节。不能仅凭"都在一个行业"就判定为上下游。

### 关联度确认方法（按可靠性排序）

1. **直接合同/订单确认** — 搜索 `"{上市公司}" "{未上市公司}" 订单 合同 合作`
2. **招股书/年报披露** — 上市公司年报中会披露前五大客户/供应商
3. **行业研报确认** — 券商研报通常明确指出供需关系
4. **供应链推断** — 基于产品/技术路线的合理推断（标为"推断"）

### 关联度分级

| 级别 | 定义 | 标识 |
|------|------|------|
| **直接绑定** | 有公开合同/订单/招股书确认 | ★★★ |
| **高度相关** | 行业研报确认 + 产品线强匹配 | ★★☆ |
| **合理推断** | 行业逻辑合理但无公开确认 | ★☆☆ |
| **间接关联** | 同生态但非直接供需关系 | ☆☆☆ |

报告中必须标注每家公司与标的的关联级别。

## 注意事项

1. **关联度虚高是最常见的分析陷阱** — 必须区分"同一个大行业"和"真正的供需关系"。例如：都是做AI的公司不一定互为上下游。
2. **标的公司未上市，财务数据不公开** — 关于标的本身的数据（营收、利润）只能从媒体报道、融资披露中获取，注明来源和可信度。
3. **产业链分析有时效性** — 标注数据截止时间，建议每季度更新。
4. **关注"含标率"** — 一家供应商如果标的公司只占其营收的 2%，那买它和买标的没什么关系。
5. **同类公司注意区分市场** — A股/港股/美股估值体系不同，不可直接横向对比 PE。
6. **警惕"蹭概念"股票** — 有些公司会刻意夸大与热门未上市公司的关系，需要交叉验证。
7. **当标的为巨头时（如字节跳动）**，供应商/客户数量极多，只取**前 5 大核心供应商 + 前 3 大直接竞争对手**，不要试图穷举。
8. **关于 ESG 和合规**：如果某家相关上市公司存在重大合规问题（财务造假、制裁风险），必须在报告中显式标注并扣分。
9. **"机器人概念股"≠"机器人收入"** — 很多被市场标为机器人供应链的公司，机器人相关收入实际占比 <5%（如卧龙电驱 600580，机器人只是其众多业务线之一）。报告中必须区分"概念标签"和"真实业绩弹性"，关联度评分中的"营收占比"子维度就是为此设计的。
10. **扣非净利润照妖镜** — 当一家公司净利润看起来不错时，必须检查扣非净利润。若政府补助等非经常性损益占比 >50%（如汉威科技 300007，2025年政府补助 1.15亿占利润 72%），必须在报告中显式标注并在"盈利能力"子维度扣分。这类公司没有真实的经营盈利能力。
11. **两梯队供应商结构** — 在实践中，供应商通常会自然分为两个梯队：(a) 高相关性纯正标的，机器人业务占比高、弹性大、但估值贵；(b) 低相关性综合巨头，基本面稳健但含标率低、弹性不足。报告中应明确区分，避免把卧龙电驱和长盛轴承放在同一个弹性预期下讨论。

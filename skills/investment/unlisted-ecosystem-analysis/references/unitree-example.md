# 宇树机器人 产业链生态分析 — 完整示例

这是 `unlisted-ecosystem-analysis` 技能的参考案例，展示了一条完整的分析链路：
未上市公司（宇树科技）→ 产业链拆解 → 8家核心供应商深度调查 → 双重打分 → 配置建议。

文件位于 `unlisted-ecosystem-analysis/testcases/宇树机器人.md`。

此案例的价值：
- 展示了"两梯队"供应商结构的典型模式：高相关性纯正标的 vs 低相关性综合巨头
- 展示了"含标率"陷阱的实际案例（卧龙电驱机器人业务占比极小但常被归类为机器人概念股）
- 展示了扣非净利润检查如何踢爆概念股（汉威科技 72% 利润来自政府补贴）
- 生态系统 68 分的结果具有代表性：产业链健康但个股分化严重，需要精选而非广撒网

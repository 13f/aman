# Acknowledgments

This project stands on the shoulders of many open-source projects and individuals. We are deeply grateful for their contributions.

## OpenClaw

[OpenClaw](https://github.com/OpenClaw) — inspiration for the multi-agent coordination patterns and skill-driven agent architecture. The design of Aman's skill system and runtime lifecycle draws from OpenClaw's pioneering work on composable agent frameworks.

## Hermes Agent

[Hermes Agent](https://github.com/HermesAgent) — foundational ideas around progressive skill disclosure, agent identity via SOUL files, and the cascade selection approach for matching user intent to installed skills. The `agentskills.io` specification and the `skm` toolchain (skm-core, skm-select, skm-embed) that underpin Aman's skill system originate from this ecosystem.

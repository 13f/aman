# IPO/打新调研

## 输入

用户提供以下至少一项：
- **新股名称**（中/英文） + 股票代码（如 `09880.HK`）
- **股票代码** + 新股名称

支持市场：**港股 (HKEX)**、**美股 (NYSE/NASDAQ)**、**A股 (沪深北)**。

## 调研流程

### 阶段 1：信息采集

按以下维度并行搜索，每条路径至少取 2 个来源交叉验证：

| 维度 | 搜索关键词模板 | 优先来源 |
|------|---------------|---------|
| 公司业务与行业 | `{公司名} IPO 招股书 主营业务 行业` | 港交所披露易、SEC EDGAR、公司官网 |
| 行业地位/竞品 | `{公司名} 行业排名 竞争对手 市场份额` | 券商研报、招股书"行业概览"章节 |
| 财务数据 | `{公司名} 招股书 营收 利润 近三年` | 招股书财务报表章节 |
| 基石投资者 | `{公司名} 基石投资者 IPO` | 财经新闻、招股书 |
| 绿鞋/超额配售 | `{公司名} 绿鞋 超额配股权` | 招股书"全球发售的架构"章节 |

### 阶段 2：数据分析与评分

对每个维度打分，最终汇总为 0-100 总分。

#### 评分维度

| 维度 | 权重 | 满分 | 评分要点 |
|------|------|------|---------|
| **行业赛道** | 25% | 25 | 赛道成长性（10分）+ 政策支持/监管友好度（8分）+ 赛道唯一性/壁垒（7分） |
| **公司基本面** | 25% | 25 | 近三年营收 CAGR（10分）+ 盈利能力/毛利率（8分）+ 行业排名/份额（7分） |
| **IPO结构质量** | 20% | 20 | 按市场：港股（基石8+绿鞋4+估值8）、A股（战配6+绿鞋3+余额包销1+回拨2+估值8）、美股（Lock-up4+绿鞋/Rule104 4+PenaltyBids1+承销团3+估值8），详见子维度说明 |
| **市场情绪** | 15% | 15 | 超额认购倍数（8分）+ 近期同类 IPO 首日表现（4分）+ 大盘环境（3分） |
| **风险因素** | 15% | 15 | 政策/监管风险（-分，倒扣，满分 5 分）+ 竞争风险（5分）+ 解禁抛压风险（5分） |

> 风险因素采用 **倒扣制**：风险越高扣分越多，满分 15 分意味着无显著风险。

#### 各子维度评分标准

**行业赛道 (25分)**
- 赛道成长性 (10分)：行业 CAGR >30% → 9-10分；15-30% → 6-8分；5-15% → 3-5分；<5% 或萎缩 → 0-2分
- 政策友好度 (8分)：国家重点支持 → 7-8分；中性 → 4-6分；强监管/打压 → 0-3分
- 唯一性/壁垒 (7分)：A股/H股独有标的，无直接竞品 → 6-7分；细分龙头但有多家竞品 → 3-5分；同质化严重 → 0-2分

**公司基本面 (25分)**
- 营收 CAGR 近三年 (10分)：>50% → 9-10分；30-50% → 7-8分；15-30% → 5-6分；0-15% → 2-4分；负增长 → 0-1分
- 盈利能力 (8分)：稳定盈利 + 毛利率 >40% → 7-8分；微利或盈亏平衡 → 4-6分；持续亏损且无改善 → 0-3分
- 行业地位 (7分)：行业 Top 3 → 6-7分；Top 10 → 4-5分；中小玩家 → 1-3分

**IPO结构质量 (20分)** — 子维度按上市市场不同，总权重不变

##### 港股

- 基石投资者 (8分)：顶级机构/国家级基金 → 7-8分；知名机构 → 5-6分；一般机构 → 2-4分；无基石 → 0-1分
- 绿鞋 (4分)：有 → 4分；无 → 0分
- 估值合理性 (8分)：PE 显著低于同行 → 7-8分；与同行持平 → 4-6分；显著高于同行 → 0-3分

##### A股

- 战略配售阵容 (6分)：国家级基金/社保/养老金领投 → 5-6分；头部公募/产业资本 → 3-4分；一般机构 → 1-2分；无战配 → 0分
- 绿鞋 (3分)：有 → 3分；无 → 0分（A股有余额包销作补充，绿鞋权重略低于港股）
- 余额包销 (1分)：主承销商承诺余额包销 → 1分；无 → 0分
- 回拨结构 (2分)：网上比例适中（≤50%）→ 2分；网上比例偏高（50-80%）→ 1分；网上比例过高（>80%）→ 0分（回拨过多导致散户抛压集中）
- 估值合理性 (8分)：PE 显著低于同行 → 7-8分；与同行持平 → 4-6分；显著高于同行 → 0-3分

##### 美股

- Lock-up 质量 (4分)：>180天且覆盖全面 → 3-4分；标准180天 → 2分；<180天 → 0-1分
- 绿鞋/Rule 104 护盘 (4分)：有绿鞋+Rule 104 披露 → 4分；仅绿鞋 → 3分；仅 Rule 104 披露 → 2分；均无 → 0分
- Penalty Bids (1分)：招股书提及 → 1分；无 → 0分
- 承销团协同能力 (3分)：≥3家顶级投行联席 → 3分；2家 → 2分；1家 → 1分
- 估值合理性 (8分)：PE/PS 显著低于同行 → 7-8分；与同行持平 → 4-6分；显著高于同行 → 0-3分

> Direct Listing 无传统承销商护盘，IPO结构质量自动扣 5 分（仅限估值+承销团可评）。
> SPAC 不计绿鞋/Lock-up 常规分，需单独评估 sponsor 质量（打分另见 SPAC 评估指引）。

**市场情绪 (15分)**
- 超额认购倍数 (8分)：>100倍 → 7-8分；50-100倍 → 5-6分；15-50倍 → 3-4分；<15倍 → 0-2分
- 近期同类 IPO 表现 (4分)：同类首日普涨 → 4分；涨跌互现 → 2-3分；普遍破发 → 0-1分
- 大盘环境 (3分)：上升趋势 → 3分；震荡 → 1-2分；下跌/恐慌 → 0分

**风险因素 (15分)** — 第3项解禁/抛压风险按市场判定

- 政策/监管风险 (5分)：无 → 5分；轻微 → 3-4分；中等不确定性 → 1-2分；重大不利政策 → 0分
- 竞争风险 (5分)：护城河宽 → 4-5分；有一定壁垒 → 2-3分；低壁垒易复制 → 0-1分
- 解禁/抛压风险 (5分)：
  - **港股**：基石锁定期长+占比高 → 4-5分；锁定期短或占比低 → 2-3分；无基石 → 0-1分
  - **A股**：控股股东锁36个月+战配锁12个月 → 4-5分；仅控股锁36个月 → 2-3分；锁定期短 → 0-1分（A股锁定期天然较长，基准偏高）
  - **美股**：Lock-up >180天+覆盖全面 → 4-5分；标准180天 → 2-3分；<180天 → 0-1分；Direct Listing 无锁定期 → 0分

## 孖展/认购倍数：正确解读指南

这是港股打新最容易误读的数据，必须区分两个层面：

### 计算公式

```
认购倍数 = 孖展申购总额 / 公开发售集资额
```

其中公开发售集资额 = 香港公开发售股数 × 招股价。港股初始公开发售通常只占总发行量的 5-10%（18C 为 5%），所以**分母天然很小**。一只总募资 7.5 亿的新股，公开发售集资额可能只有 ~0.375 亿港元——任何正常的散户热情投射上去，倍数就轻松破百破千。

### 平台显示 vs 全市场汇总

**这是最关键的分辨：**

| 显示位置 | 含义 | 举例 |
|---------|------|------|
| 券商 APP（长桥/富途/老虎） | **该平台自身的孖展数据**，分母是该券商分到的份额（远小于总公开发售），倍数天然更高 | 长桥显示 4462x，全市场可能只有 1224x |
| 财经新闻/捷利交易宝 | **全市场汇总**（综合各家券商孖展数据） | 大公报/观点网/汇港通讯报道的倍数 |

用户问"我在 XX 券商看到 Y 倍，这包含其他平台吗？" — **不包含**。各券商各自统计，分母不同会导致同一只新股的倍数在不同 APP 上差异巨大。

### 追踪孖展数据的推荐来源

按可靠性排序：
1. **汇港通讯 (infocastfn.com)** — 盘后发布当日孖展汇总，数据最及时
2. **大公报** — 综合券商数据，附带分券商明细（富途 X 亿、老虎 Y 亿）
3. **观点网 (guandian.cn)** — 提供分时段孖展数据
4. **TastyMoney / 经济通 etnet** — 实时更新孖展倍数
5. **捷利交易宝** — 新股评分 + 孖展统计
6. **券商 APP** — 仅用于查看该平台自身热度，不可当作全市场数据

搜索用关键词：`"{公司名}" "孖展" "{日期}"`

### 2026 年市场校准

2026 年港股打新极度火热：截至 4 月，年内 41 只新股中有 22 只超购 1000 倍以上。评分表中">100 倍 = 7-8 分"的标准对 2026 年已偏低。建议：
- <50x → 冷淡（0-2 分）
- 50-200x → 一般（3-4 分）
- 200-1000x → 热（5-6 分）
- 1000-5000x → 很热（7-8 分）
- >5000x → 极度狂热（8 分，但需警惕过热风险）

### 重要提醒

超额认购倍数高 ≠ 必然首日大涨。高倍数反映散户情绪，但首日表现还取决于：
- 国配机构承接意愿（国配不足额则公配再热也无用）
- 有无绿鞋托底（无绿鞋 + 高倍数更危险，抛压无人承接）
- 定价是否合理（市场价 vs 最后一轮融资价折溢价）
- 保荐人历史表现

## 18C 特专科技公司上市机制

港股 18C 章是 2023 年推出的特专科技公司上市通道，核心特征：

| 特征 | 说明 |
|------|------|
| 回拨上限 | **20%**（常规 IPO 为 50%），超购 100 倍以上即顶格回拨 |
| 初始公开发售 | 通常 **5%**（常规为 10%） |
| 适用公司 | 未盈利的特专科技公司（AI、机器人、半导体、新能源等） |
| 典型特征 | 无基石无绿鞋更常见，因未盈利机构参与意愿低 |

对打新的影响：
- 公开发售分母更小 → 倍数天然更高
- 顶格回拨仅 20% → 散户最终分到的货很少 → 中签率更低
- 无绿鞋更常见 → 首日抛压无人托底，波动更大
- 未盈利 + 高研发 → 需按 PS 估值，不可简单看 PE

## A股与美股特有维稳机制

港股有基石投资者和绿鞋双重护盘，A股和美股各有不同机制。以下逐一说明，
并在评分中按市场分别计入。

### 三地核心机制速览

| 机制 | 港股 | A股 | 美股 |
|------|------|-----|------|
| 基石/战配 | 基石（6个月锁） | 战配（12个月锁） | 无对等机制 |
| 绿鞋 | 普遍 | 大盘股常见 | 普遍（Greenshoe） |
| 承销商护盘 | 有，监管宽松 | 余额包销，偏刚性 | SEC Rule 104，偏市场化 |
| 回拨 | 有（常规50%，18C为20%） | 有，更激进（最高90%网上） | 无 |
| 限售锁 | 6个月（控股） | 36个月（控股） | 180天（合同） |
| 兜底 | 无 | 发行失败条款 | 无 |
| 惩罚性报价 | 无 | 无 | Penalty Bids |

---

### A股：五大维稳机制

#### 1. 战略配售（最接近港股基石）

向特定战略投资者定向配售，通常锁定 **12 个月**。与港股基石的关键区别：
- A股战配更强调"战略协同"（产业链上下游、技术合作），而非纯粹财务锚定
- 战配对象：产业资本、公募基金、社保基金、养老金、企业年金
- 战配比例通常 10%-30%，注册制下更为灵活
- **评分替代**：A股无基石概念，用战配阵容替代基石评分

#### 2. 超额配售选择权（绿鞋）

与港股同一机制，2001 年引入。发行人授予主承销商超额配售不超过 **15%** 的权利，
上市后 30 天内如果破发可以二级市场买入护盘。A股绿鞋特点：
- 大型IPO（农行、邮储、中国电信回A）几乎标配
- 中小盘IPO绿鞋使用较少
- 评分：有绿鞋 +3 分（vs 港股 +4 分，因A股有余额包销作为补充）

#### 3. 主承销商余额包销

承销商承诺兜底，发行不成功的部分自己吃下。这是A股特有的硬性托底机制：
- 网下申购不足额 → 主承销商全额包销
- 网上申购不足额 → 中止发行（发行失败条款触发）
- 评分影响：余额包销存在 → 额外 +1 分稳定分

#### 4. 回拨机制（A股版）

A股回拨规则与港股不同，注册制下更激进：
- 网上申购过热 → 从网下向网上回拨（最高网上可达 90%）
- 目的：抑制首日过度炒作，让更多散户中签
- 评分影响：回拨后网上比例过高 → 首日抛压集中 → 风险因素中扣 1 分

#### 5. 发行失败条款

注册制下，触发以下任一条件则中止发行：
- 网上有效申购倍数不足（<1倍）
- 网下投资者数量不足
- 这是全市场托底，极端情况才触发
- 评分影响：不计入常规评分，但需在风险提示中提及

#### 6. 限售锁定（A股独有刚性约束）

比港股和美股都严格：
- 控股股东/实控人：锁 **36 个月**
- 其他首发前股东：锁 **12 个月**
- 董监高：锁 12 个月 + 离职后 6 个月内不得转让
- 评分影响：控股股东锁定期长 → 解禁风险分散 → 风险因素 +1 分

### 美股：四大维稳机制

#### 1. Greenshoe Option（绿鞋）

同源机制，超额配售不超过 15%。美股实操中绿鞋行使更市场化：
- 承销团通过二级市场买入稳定价格
- 不设硬性买入义务，承销商有自主裁量权
- 评分：有绿鞋 +3 分（vs 港股 +4 分，因美股另有 Rule 104 补充）

#### 2. SEC Rule 104（Regulation M）

承销商主动稳定报价的合法框架，是美股最重要的护盘机制：
- 允许承销商在发行后以**不超过发行价**的价格报买单
- 必须提前在招股书中披露稳定报价意图
- 核心约束：**不能把价格推到发行价以上**（仅托底不拉升）
- 稳定期通常持续到发行后 30 天
- 评分：招股书披露 Rule 104 稳定意向 → 视为等同于有护盘机制

#### 3. Penalty Bids（惩罚性报价）

承销团内部惩罚机制，用于减少首日抛压：
- 如果承销团成员把股票卖给"快进快出"的短线客（首日即抛售），
  主承销商可以**扣减其销售佣金**
- 目的：激励承销团成员把货配给长线持有者
- 不是对所有投资者生效，仅约束承销团内部
- 评分：招股书提及 Penalty Bids → +1 分稳定分

#### 4. Lock-up Agreements（限售协议）

合同性质而非监管强制，通常 **180 天**：
- pre-IPO 股东、管理层、董事签署
- 到期"解禁日"往往是市场博弈焦点——解禁前做空、解禁后集中抛售
- 与A股的关键区别：180 天 vs 36 个月，且为合同而非监管强制
- 评分：锁定期 >180 天 → +1 分；标准 180 天 → 无加减；<180 天 → 风险因素扣 1 分

#### 5. Syndicate Covering Transactions（承销团协同补仓）

承销团在空头回补时可以从二级市场买入，形成额外买盘：
- 通常配合绿鞋使用
- 评分：承销团阵容强（多家顶级投行）→ 协同补仓能力强 → 额外 +1 分

#### 6. Direct Listings / SPACs（无传统承销商维稳）

这两种路径没有传统承销商护盘，需单独评估：
- **Direct Listing**：无承销商护盘，价格完全由开盘竞价决定，无绿鞋/Rule 104
  → IPO结构质量自动扣 5 分
- **SPAC**：有信托资金赎回权作为投资者保护（可赎回 = 保本底线），
  但无绿鞋护盘 → 不计绿鞋分，需单独评估 sponsor 质量

## 评分陷阱（必读）

以下是容易被评分表线性公式掩盖的真实风险信号，遇到时必须对相关维度做额外压分：

**陷阱 1：板块系统性破发**
当所有已上市同类股票均深度破发（-20%以上），仅靠"近期同类IPO表现"扣 3-4 分是不够的。
该信号必须同时压低：
  - IPO结构质量 → 估值合理性（同行折价意味着你的发行价实际偏贵）
  - 风险因素 → 解禁抛压（同行水下意味着你的基石锁定期满后抛压更重）
  - 市场情绪 → 大盘环境（板块黑洞效应独立于大盘）
  建议：板块内 ≥3 家公司且全部破发时，总分额外扣 3-5 分。

**陷阱 2：无绿鞋 + 板块破发叠加**
无绿鞋本身扣 4 分（IPO结构质量），但如果叠加板块系统性破发，意味着
上市后完全没有承销商托底，首日抛压无人承接。此组合必须额外扣 2-3 分
并在风险提示中列为首要风险。

**陷阱 3：净收益留存率（NRR）断崖**
对于订阅/SaaS 型业务，若净收益留存率从 >100% 跌至 <80% 且伴随着
客户留存率下降，说明老客户大幅缩减采购，增长严重依赖新客。
此信号必须在"盈利能力"子维度中额外扣 1-2 分，并在风险提示中列出。

**陷阱 4：A股回拨比例过高（散户抛压陷阱）**
当A股网上回拨比例超过 80%，意味着绝大多数筹码在散户手中，首日集中抛售概率极高。
此信号必须：
  - 风险因素 → 解禁/抛压风险额外扣 1 分
  - 在报告风险提示中列为第 1 条风险
  - 建议：网上回拨 >80% 时，A股 IPO 总分额外扣 2 分

**陷阱 5：美股 Direct Listing 无护盘**
Direct Listing 没有承销商、没有绿鞋、没有 Rule 104、没有 Lock-up，
所有维稳机制均不存在。遇到 Direct Listing 必须：
  - IPO结构质量自动扣 5 分（已在评分中注明）
  - 风险因素 → 解禁/抛压风险直接给 0 分
  - 在报告最显眼位置标注"⚠️ Direct Listing — 无任何价格维稳机制"
  - 总分额外扣 3 分作为结构风险惩罚

**陷阱 6：A股限售锁定到期日集中（解禁洪水）**
A股虽然锁定严格（控股36个月），但到期日是固定日期。
当多只同板块新股限售集中在同一季度解禁时，板块会面临集中抛压。
此信号必须在风险提示中提及，并在"解禁/抛压风险"中扣 1 分。
搜索方法：`{公司名} 限售股解禁 日期` + `{行业} 限售股解禁 202X年X季度`

**陷阱 7：美股 Lock-up 到期 + 财报发布叠加**
美股 Lock-up 通常 180 天，解禁日常与上市后第二个财报季重合。
如果解禁日正好在财报发布后 1-2 周，可能出现"利好出货"或"借财报利好解禁抛售"。
此信号不扣分但必须在风险提示中列出时间线，提醒用户关注。

## 深度追问处理（调研后的 follow-up）

用户读完 IPO 调研报告后，常追问某几个具体维度的深度分析。这类问题
不需要重跑整个评分框架，采用 **搜索 → 交叉验证 → 结构化回答** 模式即可。

### 常见追问类型

| 追问类型 | 示例 | 处理方式 |
|---------|------|---------|
| 利润变动拆解 | "净利润从 X 跌到 Y 是什么原因？" | 先查 `{公司名} {年份} 净利润 下降原因`，然后提取招股书/新闻中的经调整利润、费用明细，区分**经营因素**（毛利率/费用率/营收增速）和**非经营因素**（股份支付/上市费用/一次性减值）。用表格对比「年内利润 vs 经调整利润」是核心洞察起点 |
| 历史 IPO 失败原因 | "为什么之前科创板/创业板失败了？" | 搜索 `{公司名} 科创板/IPO 撤回 原因 终止`，聚焦：财务底子（持续亏损/资不抵债）、客户集中度、核心技术争议（共有专利/外购部件）、未决诉讼。用时间线 + 分点原因结构呈现 |
| 估值对比 | "跟同行比 PE/PS 贵吗？" | 查同行招股书或券商研报，做横向对比表 |
| 行业政策风险 | "这个赛道政策会变吗？" | 搜索近期政策文件/监管动态，关注处罚案例和行业整顿信号 |
| A股发行失败原因 | "为什么之前科创板被否/撤回了？" | 搜索 `{公司名} 科创板/创业板 终止 撤回 原因`，聚焦：板块定位不符（科创属性/三创四新）、财务底子（持续亏损/资不抵债）、客户集中度、核心技术争议（共有专利/外购部件）、未决诉讼。区分"保荐人撤材料"和"上市委否决"——前者占多数但实质等同于失败 |
| 美股 Lock-up 解禁 | "解禁日前后怎么操作？" | 查 S-1 中"Shares Eligible for Future Sale"章节，锁定解禁日期 + 解禁股数占总股本比例 + 是否有解禁前做空仓位积累。解禁日前后 1-2 周通常波动加剧 |
| 战配 vs 基石对比 | "A股战配和港股基石有什么区别？" | 对比：锁定期（12月 vs 6月）、参与方性质（战略协同 vs 财务锚定）、对打新者的信号含义（战配更偏产业认可，基石更偏估值背书） |

### 关键原则

- **经调整利润是照妖镜**：港股招股书必披露经调整净利润，当账面利润和经调整利润差距大时，先查调整项明细（股份支付、上市开支是最常见的两项）
- **客户集中度是硬伤还是行业特性**：航空航天/军工类客户集中是天生的（只有几家国企客户），但 90%+ 的集中度仍然致命。区分"行业特性"（情有可原但仍是风险）和"经营缺陷"
- **保荐人撤回 ≠ 被否**：科创板/创业板终止案例中，多数是保荐人主动撤材料，但撤材料本身就说明过会无望，实质等同于失败
- **交叉验证**：同一数据至少 2 个来源确认，尤其是利润/营收数字——不同媒体可能引用不同口径（经调整 vs 未调整，合并 vs 母公司）

对于已开始招股的港股新股，**优先搜索财经新闻聚合网站**
（新浪财经、hket 经济日报、经济通 etnet、东方财富、格隆汇）

### 搜索工具故障降级方案

当 `web_search` / `web_extract` (Tavily) 不可用（返回 432/5xx 错误）时，
按以下降级链执行，优先级从高到低：

**第一降级：DuckDuckGo HTML 搜索 + curl 抓取**

这是最可靠的方案 — DuckDuckGo 的 HTML 版（非 JS 版）反爬门槛低，
配合 curl 可直接获取搜索结果和页面内容。

步骤 1 — 获取搜索链接：
```bash
curl -sL "https://html.duckduckgo.com/html/?q={URL编码关键词}" \
  -H "User-Agent: Mozilla/5.0" \
  | grep -oE '<a[^>]*class="result__a"[^>]*>[^<]*</a>'
```

步骤 2 — 提取目标页面文本（推荐脚本见 `scripts/extract_visible_text.py`）：
```bash
curl -sL -H "User-Agent: Mozilla/5.0" "<目标URL>" \
  | python3 -c "
import sys, re, html
text = sys.stdin.read()
text = re.sub(r'<script[^>]*>.*?</script>', '', text, flags=re.DOTALL)
text = re.sub(r'<style[^>]*>.*?</style>', '', text, flags=re.DOTALL)
text = re.sub(r'<[^>]+>', '\n', text)
text = html.unescape(text)
lines = [l.strip() for l in text.split('\n') if l.strip()]
for l in lines:
    if len(l) > 15:
        print(l)
"
```

步骤 3 — 针对 IPO 数据，可进一步用关键词过滤：
```python
for l in lines:
    if any(kw in l for kw in ['营收','利润','亏损','基石','孖展',
        '认购','估值','上市','发售','招股','元','万','亿']):
        print(l)
```

**第二降级：浏览器导航到具体新闻 URL**

当已知目标 URL（从 DuckDuckGo 搜索结果中提取）时，可直接用
`browser_navigate` 访问。但注意：Google/Bing 搜索首页常触发
CAPTCHA，不建议用于搜索引擎查询，仅用于直接访问已知新闻页。

**第三降级：直接 curl 已知财经源**

以下源对 curl 友好度较高（已验证）：
- news.qq.com/rain/ — 腾讯新闻（瑞恩资本等 IPO 快讯首发）
- 163.com/dy/ — 网易订阅
- finet.hk — 财华社（IPO 追踪系列）
- stcn.com — 证券时报
- xueqiu.com/S/ — 雪球个股页

以下源可能拦截 curl（CloudFront/CDN 反爬）：
- hket.com（CloudFront 403）
- finance.sina.com.cn（部分路径拦截）

**注意事项**：
- DuckDuckGo 连续请求过多会触发验证码，每次搜索间隔 ≥3 秒
- 终端 curl 必须带 `-H "User-Agent: Mozilla/5.0"` 否则多数财经站拒绝
- 部分中文站点编码为 gb2312，需 `iconv -f gb2312 -t utf-8` 转码
- 此方案完全绕过 Tavily，不受 web_search 后端故障影响

## 实战技巧：快速估算中签率

港股新股的中签率取决于三个变量：
1. **公开发售手数**（初始手数 → 回拨后手数）
2. **申购人数**（甲组 + 乙组）
3. **红鞋机制**下的分配规则（甲组一手优先）

快速估算：
- 顶格回拨手数 = 总发行股数 × 20% / 每手股数
- 一手党中签率 ≈ 回拨后甲组手数 / (甲组总申购人数 × 1.5)  （系数 1.5 补偿梯级分配）
- 乙组稳中一手门槛：看乙组申购人数 — 通常乙组人数在 5000-20000 之间

实用参考：乐动机器人（6707x 超购，公开发售手数与翼菲接近，约 4-5 万手），20.5 万人申购，一手中签率约 5-10%。

## 注意事项

1. **所有财务数据以招股书为准**，券商研报为补充参考。
2. **基石投资者**信息必须在招股书中确认，新闻传闻需注明"仅供参考"。
3. **超额认购倍数**会动态变化，注明数据截止时间和来源（全市场/某平台）。
4. 对于尚未开始招股的新股，标注"招股书未发布，以下为预披露信息"。
5. 评分需**可追溯** — 每项得分附简要理由（一句话即可）。
6. 港股需要额外关注：(1) 是否有第二上市/双重主要上市，(2) H股全流通，(3) 港股通纳入预期，(4) 是否适用 18C 机制（影响回拨上限和公开发售比例）。
7. 报告中【主要竞争对手】推荐使用表格形式展示，包含竞品股票代码、主攻场景、营收规模和港股状态（破发/递表中），便于直观对比。
8. **遇到用户询问孖展倍数时**，必须主动解释：该数据来自哪个平台（单一券商 vs 全市场），分母是什么（公开发售集资额），以及倍数高的核心原因（分母小 vs 真正需求大）。
